Legislator/candidate headshots go here.
Name each file <slug>.jpg where slug = lowercase name, non-alphanumerics -> hyphens.
Examples:
  Kathleen C. Hochul  -> kathleen-c-hochul.jpg
  J Gustavo Rivera    -> j-gustavo-rivera.jpg
  Amy Paulin          -> amy-paulin.jpg
Missing photos fall back to initials automatically.
